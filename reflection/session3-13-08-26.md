This class was about making a square using swing for GUI window
For creating this, I imported JFrame class of swing
Along with JFrame, I imported Color to provide color to the outline
and I imported Graphics.
From the graphics, i used the "drawRect" function to draw a rectangle by providing x and y coordinate, width and height in the parameters
Apart from this, JFrame decides what happens on the screen-
It decides the window size, here i took 400x400 pixels,
it decides what happens when user clicks X button, here i close the window and so on.
