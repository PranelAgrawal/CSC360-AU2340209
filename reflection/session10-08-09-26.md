## Notes

### 1. Exceptions

* **Runtime Exceptions:** There are different types of exceptions in programming; runtime exceptions occur and are caught while the program is actively executing.
* **Try-Catch Blocks:** Commonly used (such as in JavaScript) to handle runtime errors cleanly:
    * `try` block: Contains the main application logic intended for execution.
    * `catch` block: Executes only when an error or unexpected exception occurs inside the `try` block, preventing application crashes.

---

### 2. Generics in Java

* Generics allow classes, interfaces, and methods to operate on specified types while providing compile-time type safety.
* Enables writing reusable, type-safe components without the need for manual type casting.

---

### 3. Collections in Java

Key collection structures used to organize and manipulate groups of objects:

* **ArrayList:** Resizable-array implementation offering fast index-based lookups.
* **LinkedList:** Doubly-linked list implementation suited for frequent insertions and deletions.
* **Queue:** Collection tailored for holding elements prior to processing (typically FIFO order).
* **HashSet:** Hash-table-based collection storing unique items with no duplicates.

---

### 4. Views

* A view provides a read-only subset of existing data or a file.
* It does not allow direct modification of the underlying source; it serves purely to let the user inspect content without risk of accidental edits.

---

### 5. Event Handling & GUI Interaction

* **Event Handling in Graphical Interfaces:**
    * A mechanism for the user to communicate intent to the software (e.g., clicks, keystrokes, gestures).
    * Unique to Graphical User Interfaces (GUIs), where interactive elements live inside a window; console/terminal interfaces generally do not support event-driven interaction in this way.
* **Event Hierarchy & Propagation:**
    * Defines the sequence or chain through which an event is passed and consumed.
    * **Example:** Moving the mouse inside a PDF opened in Google Chrome propagates from the PDF viewer $\to$ Chrome tab $\to$ browser window $\to$ operating system.

---

### 6. Common GUI Controls

* **Radio Button:** Presents a group of mutually exclusive options where the user can pick only one selection.
* **Checkbox:** Allows non-exclusive selections, letting the user toggle zero, one, or multiple options independently.
* **Slider:** A continuous or stepped sliding control used to select a numeric value within a range (e.g., an audio volume slider).

---

### 7. Dialog Boxes

* A dialog box is a temporary pop-up window displayed over the primary interface.
* **Context Preservation:** Keeps the main workspace visible in the background so the user never loses track of their ongoing task.
* **Modal Focus:** Directs immediate user attention to a critical action, prompt, or confirmation before they can continue.
